# PR Pattaya Pickleball

The former Pickleball Pattaya record now resolves to **PR Pattaya Pickleball** at the same Pratamnak Soi 6 location. The current Maps listing uses the PR name, address and phone above, while the operator's older generic site still calls the venue Pattaya Pickleball Club and describes the Soi 6 courts. This is a rename, not a second venue.

Maps currently lists two daily playing windows, 07:00-10:00 and 16:00-19:00, and reports open play every day. The older operator site still says 07:00-21:00, so the newer listing hours are used and players should confirm before arriving.

The operator site describes two full-size courts, permanent nets, lighting, equipment and beginner coaching. No current public tariff was available, so the old price assumptions have been removed.
