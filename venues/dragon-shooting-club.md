# Dragon Shooting Club

## Current details

The live listing uses **Dragon Shooting Club**, while the operator's own site also uses **Golden Dragon Shooting Club**. Both point to the indoor range at 105/2 Moo 8, Bang Lamung, open 09:00–18:00 every day.

The current Maps listing publishes +66 64 794 2625; the operator site still publishes +66 80 063 8222. Because the two live sources conflict, both are retained and visitors should use the Maps number first. The earlier record's unsupported superlatives and age rules remain removed.
