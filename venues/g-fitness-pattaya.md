# G Fitness Pattaya

G Fitness occupies a two-storey building at IG Center on Chaiyaphruek 2 Road. The operator describes separate weight-training, cardio, indoor-class and outdoor functional-training areas. Published class examples include yoga, Zumba, aerobic dance, BodyCombat, BodyPump, HIIT and Muay Thai, but the live class timetable should be confirmed.

## Price and first visit

No current first-hand tariff was published. Ask about a drop-in visit, membership terms, class inclusion and personal-training fees. Both the operator site and current Maps listing show daily opening from 07:00 to 21:00. The venue is east of Jomtien Beach, so use the Maps pin rather than assuming a beachfront location.
